# CS-330-Repos
How I approach designing software

My general plan when designing software is to build out the basic structure and interate repeatedly so as to find my intended workflow that enables intended effects, usually developed through creative testing in every aspect the project so as to find my final intended structure as early as possible, as well as identify any challenges that may arise. This allows me to find expected required leniency and environmental restrictions, as well as define my ambitions early on in development. A major skill I developed throughout the course of this project was the use of primitives so as to create complex structures. By building the largest objects and finetuning details alongside this inclusion schedule, this allowed me to refine my skills iteratively as well as avoid developmental burnout, which I suspect to be extremely valuable in certain computer science environments.

How I approach developing programs

When designing and developing programs, I focus on the aforementioned iterative process so as to test each individual component. Within the context of this project, I started with general rendering and camera movement/positioning, then added the textures, lighting, and interactions required to make the scene feel congruent and provide the user with the correct means of operation over the course of the remainder of the project. By repeatedly iterating over these developmental aspects, I was capable of retaining how to interact with scene variables and properly tweak them throughout the testing of the environment with minimal backtracking.

How computer science helps me reach my goals

Throughout the development of this project, I was constantly learning new things about how to enable a three-dimensional scene with tools such as primitives, lighting detailing, and texture post-processing. This allowed me to practically employ teachings I have previously only understood in theory, as well as practice newly learned concepts iteratively so as to train myself throughout the development process. This will enable me to properly engage with real-world applications of having to debug and add to existing codebases as well as generally debug code in such an environment.
